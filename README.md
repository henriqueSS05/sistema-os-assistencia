# Assistência Técnica Web

Sistema em HTML, CSS e JavaScript com Node.js, Express e SQLite.

## Requisitos
- Node.js 20 ou superior
- VS Code

## Como executar

Abra a pasta no VS Code e rode:

```bash
npm install
npm start
```

Depois abra no navegador:

```text
http://localhost:3000
```

## Banco de dados
O arquivo SQLite é criado automaticamente em:

```text
database/assistencia.db
```

## Funções incluídas
- Painel com indicadores
- Nova Ordem de Serviço
- Cliente dentro da própria OS
- Dados do aparelho
- Defeito e diagnóstico
- Serviço, peças e testes
- Valores e cálculo de total
- Status
- Busca
- Edição
- Exclusão
- SQLite
